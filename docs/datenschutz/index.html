Datenschutz

FoldPage ist eine lokale Lese-App. Die App benötigt kein Konto und verwendet weder Analyse- noch Crash-Reporting-Dienste. Die Betreiberin erhebt über die App keine personenbezogenen Daten und gibt keine Daten an Dritte weiter.

In der App gespeicherte Daten

Gespeicherte Seiten, Lesefortschritt, Markierungen und die Bibliothek bleiben im privaten App-Speicher auf dem Gerät. Eine Cloud-Synchronisierung findet nicht statt.

Abruf gespeicherter Seiten

Wenn du eine Seite zum Speichern auswählst, ruft FoldPage diese Seite direkt von deren Server ab. Dabei erhält der jeweilige Server technisch notwendige Verbindungsdaten, insbesondere die IP-Adresse. FoldPage übermittelt darüber hinaus keine App- oder Bibliotheksdaten.

Cookies und Einwilligungen

Die App setzt keine Cookies oder vergleichbare Tracking-Technologien ein. Es gibt daher keine einwilligungspflichtige Datenverarbeitung und kein Cookie-Banner.

Bereitstellung dieser Website durch GitHub Pages

Diese Website wird von GitHub, Inc. als Auftragsverarbeiter ausgeliefert. GitHub führt dabei technisch notwendige Server-Logs, die insbesondere IP-Adresse, Zeitpunkt und angeforderte Datei enthalten können. Weitere Informationen enthält die Datenschutzerklärung von GitHub.
